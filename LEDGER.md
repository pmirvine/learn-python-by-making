# Ledger

What each chapter *actually* taught, what it promised later chapters would explain, and what it handed on for reuse. `PLAN.md` is the intention; this is the record. Update it as each chapter is finished, and read it before writing the next.

Rules it exists to enforce:

- **Nothing is used before it's taught.** If a chapter needs a concept that isn't in an earlier "Taught" list, it teaches it or does without.
- **Every promise is kept.** When a chapter says "Project N explains this", it goes in N's "Owes" list here.
- **Reused code keeps its shape.** When a later project depends on an earlier one's package, the API recorded here is the contract.

Type-in: ANSI colour bars (`end=""`, `{name:^8}`, nested `for` over `range`, a list literal, all unexplained).

**Owes:** P1 `**`, `/`, `//`. P3 type hints; `enumerate` as the "better way" than indexing `NAMES[colour]`. P4 `if __name__ == "__main__"` in full; `uv add` to a project. P5 packaged layout. P2 the debugger. P27 pip, venv and the older tools.

**Owes:** P3 `enumerate` ("something better" than `range(len())`); slices follow the range convention; tests. P4 the mutable-default-argument gotcha ("evil twin, involving lists"); why immutability matters. P7 functions as values, and better ways than module-level `pen`. P16 a Logo interpreter.

**Infrastructure:** `tests/paperturtle.py` (a fake `turtle` that records and renders to PNG), `tests/turtle_runner.py` (runs a program against the real turtle, flat out, where a display exists), `scripts/screenshots_p02.py`.

Generator expressions seen in the type-in, unexplained. Tools: `uv add --dev`; pytest: `test_*.py`, `test_*` functions, bare `assert`, reading a failure report, `pytest.approx`, testing random code by properties and by `random.seed`, "return, don't print" for testability; VS Code Testing panel, Debug Test; `uv run ruff check`, rule codes, `ruff format`; ruff's RUF007 as a worked example. Rhythm is now run, test, lint, diff, commit.

**Owes:** P4 switch on a type checker (Pylance `basic`); why dict keys must be unchangeable (hashing); `str.join` "looks back to front, Project 4 explains"; `__name__` "takes the lid off". P6 generator expressions ("a bit more to it than that"). P7 floats, the whole story (`0.1 + 0.2`); functions as values taken "a long way further".

**Layout note:** flat project with `test_main.py` beside `main.py`; `scripts/check_all.py` handles both this and `tests/`.
